# assets/zin

Canonical ZIN store. Do not drop files here by hand; use `../drop/` and
`python scripts/ingest_assets.py`.

| Dir | Role |
|---|---|
| `workbook/` | Gold spreadsheet + codebook |
| `bundles/int/` | Intramural (hospital) PDF zips |
| `bundles/gvs/` | GVS (pharmacy) PDF zips |
| `extracts/` | GVS section text |
| `brief/` | PROJECT_BRIEF + STATE |
| `meta/` | Generated manifests |

INT = ziekenhuisvergoeding. GVS = Geneesmiddelenvergoedingssysteem.
Both are tracks of Zorginstituut Nederland.
