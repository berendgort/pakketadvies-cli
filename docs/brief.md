# Brief

## Original chat (25 Sep 2026)

Bram found that one form of dossiers was missing from the ZIN site and that
there was no page listing every advice. He built an Excel index from site
history, scraped the dossier list, and extracted arguments and precedents from
PDFs into a searchable database (about $1200 in tokens that month). The sheet
filters by dossier, indication group, and treatment line. The ZIN website is
painful to search. The useful question is when ZIN first used a given argument
or advice pattern.

## Company note (same day)

The best outcome is a company that drafts dossiers from this archive and can
license the same shape to large pharma once the corpus expands to the UK
(NICE), the Nordics, Germany, and France. This repo ships the ZIN citation
CLI. It does not draft dossiers or sell licenses. Another agency is another
folder under `data/`.
